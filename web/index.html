PC Control
Версия 2.3.0 · Build 2026.10

Интеллектуальная панель удалённого управления персональным компьютером. Поддерживает потоковую трансляцию рабочего стола и системного звука через WebRTC, двусторонний микрофон, детальное управление медиаплеером YouTube Music, контроль процессов и дистанционное включение компьютера через локальную сеть и Tailscale.

Разработчик: Lavi
Платформа: Windows 11 · Android Client
Пользовательские заметки:
Система полностью автономна, работает без сторонних облачных сервисов. Поддерживает защищённое подключение по сквозному протоколу Tailscale.
