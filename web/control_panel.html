Initial System Setup
Automatically preparing components and installing required Python libraries...
1
Python Libraries REQUIRED ...
Required step. Installs essential packages (Flask, Pillow, Winsdk, etc.) required for the server to run.
2
Tailscale VPN Secure Tunnel NOT REQUIRED
Only needed to control your PC via mobile internet outside your home. If you only control it over home Wi-Fi, you can skip this step.
3
Server Auth Password REQUIRED (Security)
Protects your server from unauthorized access. A secure password is generated automatically — you can change it anytime to your private password.
4
Windows Defender Firewall NOT REQUIRED (Recommended) ...
Not strictly required for initial launch, but highly recommended for security. Restricts port 5000 to home network and Tailscale, isolating the server from external threats.
5
Windows Automatic Sign-In NOT REQUIRED Optional
Configure automatic sign-in into Windows without entering a password at lockscreen on startup (ideal for Wake-on-LAN).
  1. Click “Configure” to open the Windows system utility netplwiz.
  2. Select the user account for which automatic sign-in should be configured.
  3. Find the option “Users must enter a user name and password” and uncheck it. Depending on the Windows version and system configuration, this option may not be available.
  4. Click “Apply”.
  5. If Windows requests the account password, enter it and confirm the changes.
  6. Restart the computer and verify that automatic sign-in works.
If the required option is missing:
In some Windows 10 and Windows 11 configurations, automatic sign-in through netplwiz may be unavailable due to Windows Hello settings. In that case, check Settings → Accounts → Sign-in options, including the setting that requires Windows Hello sign-in for Microsoft accounts.
