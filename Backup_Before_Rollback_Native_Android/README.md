# Резервная копия перед откатом нативной переработки Android

Данная папка содержит файлы и полный diff-патч нативной переработки Android (коммит `4ae5bdb`), созданной в ходе задачи:
«Критическое исправление Android APK, полная нативная реализация, восстановление управления ПК и единый дизайн».

## Содержимое
- `ApiClient.java` — REST/HTTP клиент для нативных запросов к серверу.
- `NativeDashboardView.java` — нативный Android Dashboard интерфейс (заменивший оригинальный веб-интерфейс).
- `MainActivity.java` — версия MainActivity с подключением NativeDashboardView и ApiClient.
- `stream.js` — скрипт потока из коммита `4ae5bdb`.
- `changes_from_native_overhaul.patch` — полный git diff между стабильным состоянием оригинального интерфейса `8a2d551` и нативной переработкой `4ae5bdb`.

## Назначение
Сохранение всех наработок нативной реализации безвозвратно перед полным возвратом к оригинальному пользовательскому интерфейсу (WebView + нативный плеер NativeScreenView).
