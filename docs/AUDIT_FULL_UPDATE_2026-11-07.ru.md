# Проверка полного обновления — 7 ноября 2026

## Исправленные проблемы

1. Прежний механизм заменял только Launcher.exe, оставляя сервер, интерфейс и зависимости от старой сборки. Теперь используется полный пакет с манифестом всех распространяемых файлов.
2. Сравнение версий могло пропустить изменения без увеличения номера версии. Теперь сравниваются SHA-256 файлов и идентификатор сборки, включающий revision.
3. Отсутствовали полноценные откат и восстановление прерванной установки. Добавлены отдельный процесс со своей копией Python, журнал операции, резервные копии и восстановление через Launcher.exe.
4. Успех загрузки больше не означает успех установки: после замены проверяются исполняемый файл лаунчера, ответ панели своей установки, основные библиотеки и ранее работавший сервер.
5. Устаревшие файлы предыдущей поставки удаляются по манифесту. Настройки и файлы пользователя вне манифеста сохраняются.
6. Кнопки обновления и старый updater.bat ведут к одному механизму в лаунчере. Отдельная процедура замены только EXE удалена.

## Оптимизация и защита от ошибок

- Весь пакет проверяется, но перезаписываются только изменённые файлы. В практическом сценарии заменены HTML и манифест, удалён один устаревший модуль; тысячи неизменённых библиотек не перезаписывались.
- Повторные проверки используют кеш хешей с размером и временными метками; перед установкой содержимое проверяется заново.
- Проверяются хеши метаданных, архива и каждого файла, состав архива, пути, символьные ссылки, совпадение релиза, свободное место и ограничения размера.
- Операции управления процессами ограничены текущей установкой. На время установки предотвращается автоматический перезапуск её процессов watchdog.
- Проверка сборочного архива выявляет изменение исходных файлов прямо во время упаковки.

## Границы проверки

Сетевой источник в испытаниях обновления заменяется локальными релизами. Это позволяет намеренно подавать неисправную сборку; установка, процессы Windows, HTTP, браузерная кнопка, проверка работоспособности и откат реальные. GitHub Actions и публикация этой сборки в живом GitHub из данного чата не запускались.

Мобильная проверка выполнена изменением размеров браузера, без физического телефона. Обновление APK на самом телефоне, аппаратное отключение питания, перезагрузка Windows и все возможные внешние антивирусы не проверялись. Системные действия сервера при испытаниях ограничены тестовым режимом; работоспособность управления физическим оборудованием этим отчётом не подтверждается.
