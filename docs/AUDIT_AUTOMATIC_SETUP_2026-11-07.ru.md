# Автонастройка сервера и Tailscale — 7 ноября 2026

## Вывод

Настройка сервера доступна через лаунчер без редактирования кода/config.json и ручного запуска BAT. Но сценарий «человек вообще ничего не подтверждает» не обеспечивается: Windows может запросить права администратора, Tailscale требует входа пользователя, Android — разрешения установки. Wake-on-LAN зависит от оборудования и BIOS/UEFI; параметры отдельного устройства-ретранслятора нельзя достоверно угадать по сети.

## Найденные и исправленные ошибки

1. MAC определялся по первому активному адаптеру, независимо от LAN IP. Теперь IP и MAC выбираются из одного работающего адаптера; предпочтение отдаётся адаптеру маршрута. Виртуальные адаптеры с известными именами исключаются. При отсутствии подходящего адаптера возвращаются пустые значения, а не шаблонный MAC.
2. Настройки определялись только при создании config.json и устаревали после смены сети/входа Tailscale. Для новых установок включён автоматический режим. Пока панель запущена, адреса обновляются при опросе состояния, не чаще раза в 10 секунд. При следующем запуске обнаруживаются заново.
3. Добавлена кнопка «Авто IP / MAC / VPN»: определяет и сохраняет значения, включает автоматический режим. Правка IP/MAC/VPN вручную отключает его; изменение только портов не отключает. Порты, пароль, CORS и адрес ретранслятора не подменяются автоопределением. Для ранее существовавших ручных настроек автоматический режим включается явной кнопкой.
4. При обновлении формы автоопределения обнаружена гонка с вводом нового порта. Поля блокируются на время операции, чтобы поздний ответ не стирал ввод.
5. Наличие адреса Tailscale ошибочно считалось подключением даже при Stopped. Теперь учитывается BackendState=Running и реальный IPv4 из CLI. При наличии IPv6 первым выбирается пригодный IPv4. Аккаунт определяется по UserID своего узла, а не первого пользователя в списке.
6. После авторизации Tailscale его адрес переносится в автоматические настройки сервера. При отключении в автоматическом режиме VPN-адрес очищается, чтобы не выдавать старое подключение за рабочее.
7. При отсутствии Tailscale кнопка теперь скачивает официальный EXE, проверяет подпись Windows и издателя Tailscale и запускает установщик. Пользователь подтверждает установку и выполняет вход. Открытие интерфейса Tailscale не отмечается успешным, если адрес интерфейса не отвечает.
8. Реальный прогон загрузки выявил зависание проверки подписи из-за унаследованного PSModulePath. Окружение для Windows PowerShell исправлено; повторный прогон скачивания и проверки подписи прошёл успешно.

Не каждой кнопке нужен BAT: запуск/остановка, сохранение настроек и другие операции реализованы Python-функциями. Отсутствие вызова BAT само по себе не является неисправностью. Сборка APK из исходников требует SDK и намеренно недоступна в пользовательском ZIP; готовый APK включён.

Финальный чистый ZIP прошёл `tests/audit_clean_install.py`: дополнительно проверены соответствие MAC реальному LAN-адаптеру, кнопка автоопределения, сохранение сети/пароля/CORS, запуск сервера кнопкой QR, независимое декодирование QR, скачивание APK с совпадающим хешем и восстановление настроек после перезапуска. Отчёт и скриншоты: `scratch/Чистый ZIP 20261107-020709/acceptance.json`. Ошибок JavaScript нет, `pip check` успешен. Предыдущий неуспешный прогон выявил описанную гонку формы; этот результат получен после её исправления.

## Что не подтверждено испытанием

- Установка Tailscale на полностью чистой Windows и вход в новый аккаунт. Проверены загрузка/подпись установщика и уже установленный клиент; состояние системы и аккаунт пользователя не сбрасывались.
- Соединение с физического телефона через другой интернет-канал/Tailscale. Успешный запрос по VPN-IP с того же ПК не доказывает прохождение удалённого трафика и правил tailnet.
- Реальное изменение правил Firewall, Windows Hello, netplwiz и автоматического входа Windows. Связи с обработчиками/скриптами и обработка части ошибок проверены, но системные параметры пользователя не изменялись.
- Пробуждение выключенного ПК, BIOS/UEFI, питание сетевой карты, настройка отдельного WoL-ретранслятора, разрешения Android и установка APK на физическом устройстве.
- Автоматическая передача настроек из QR веб-пульта в установленный APK: пока адрес и пароль вводятся в интерфейсе APK, без редактирования файлов.

Смена LAN IP во время открытого соединения может потребовать переподключения телефона по новому QR. Режим без редактирования файлов не равен отсутствию действий пользователя.
